# DriveHub Germany Landing Page

A premium, interactive, single-page driving school comparison website designed for **DriveHub Germany**. It helps users compare certified driving schools, search by city and license type, and book driving instructors.

## Features

- **Interactive Search Widget**: Users can filter driving schools by city (e.g., Berlin, Munich, Hamburg), license type (Class B, A, BE, etc.), transmission preference (Manual or Automatic), language of instruction, and preferred start date.
- **Smart Driving School Listings**: Responsive grid cards showing ratings, reviews, pricing, locations, and transmission types with quick bookmarking and school comparison features.
- **Comparison Modal**: Select multiple driving schools to compare their details (price, rating, reviews, transmission, etc.) side-by-side.
- **Dynamic "Why Choose Us" Timeline**: Showcases why students choose DriveHub (Real student reviews, certified instructors, price matching, and success tracking).
- **Interactive City Map**: Highlight driving school density with an interactive SVG map of German states and cities (Berlin, Munich, Hamburg, Frankfurt, Cologne). Includes auto-geolocation option.
- **Instructor Spotlights**: Browse instructor profiles, view available slots, and watch simulation videos.
- **Step-by-Step License Journey Tracker**: An interactive scroll-based timeline showing the student journey from choosing a school to getting licensed.
- **FAQ and Newsletter**: Filterable FAQs by category (Pricing, License Types, Cancellation) and a styled newsletter subscription form.
- **Fully Responsive Layout**: Premium dark/light themes, sleek glassmorphism panels, customized typography (Clash Display, General Sans, Satoshi), and smooth micro-animations.

## Tech Stack & Structure

- **HTML5 & CSS3**: Custom styles, responsive grid layouts, SVG interactive maps, and animation keyframes.
- **JavaScript & DC Runtime**: Incorporates `support.js` (a lightweight React-based custom web runtime) for state management (filtering list, comparing items, mega-menu, dropdown toggles, map city hovers, and tab switches).
- **Assets**: Styled state illustrations and logos within the `uploads/` folder.

## Getting Started / Local Development

To view the landing page locally:
1. Simply open `DriveHub Germany.dc.html` or `index.html` directly in any web browser.
2. Ensure `support.js` and the `uploads/` folder remain in the same directory structure.
